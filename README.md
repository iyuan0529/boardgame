# 🎲 桌游助手 Board Game Helper

一个功能丰富的桌游辅助工具，无需服务器，纯浏览器运行。

## 功能

- 👤 **玩家设置** - 自定义玩家名称、头像(12张)、头像边框颜色
- 🎲 **起始玩家** - 全屏炫酷摇号，显示随机恶搞消息
- 🃏 **卡牌抽取** - 17张卡牌随机抽取，支持双指缩放
- 🎭 **身份分配** - 狼人杀等身份类游戏分配（支持播报）
- ⏱️ **游戏计时** - 预设/自定义计时，时间到闪光+语音播报
- 🏳️ **计分板** - 多局积分，自动累计总分
- 📋 **猜词** - 6组词库+自定义词库，模糊显示
- 📈 **股市预测** - 股票走势预测游戏
